# Vite SPA Boilerplate

A minimal boilerplate for building Single Page Applications (SPAs) using [Vite](https://vitejs.dev/).

## Features

- Fast development server with Hot Module Replacement (HMR)
- Optimized production builds
- Modern ES module support
- Easy to extend with your preferred framework (React, Vue, Svelte, etc.)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or higher
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/maximn-png/vite-spa-boilerplate.git
cd vite-spa-boilerplate

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
